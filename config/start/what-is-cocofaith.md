# 什么是 CoCoFaith

CoCoFaith 是一套运行在 Koishi 上的群聊玩法插件。

玩家可以注册信仰、获得金币和登神分、收集物品、使用称号、加入俱乐部，也可以参与恶魔轮盘等群聊玩法。

如果你只是想把机器人跑起来，可以直接看 [快速开始](./quick-start)。

## 它由哪些插件组成

CoCoFaith v3 分成三个插件，部署时需要按顺序加载。

| 插件 | 做什么 | 必须吗 |
| --- | --- | --- |
| CoCoFaith Core | 保存玩家 UID、身份、金币、背包、物品、信仰、职业和每日刷新数据。 | 必须 |
| CoCoFaith Business | 提供玩家能使用的命令和玩法。 | 必须 |
| CoCoFaith Adapter | 连接具体聊天平台。当前配套的是 QQ 官方机器人 Adapter。 | 按平台选择 |

加载顺序：

```text
数据库插件
→ CoCoFaith Core
→ CoCoFaith Business
→ CoCoFaith Adapter
```

## 玩家能玩什么

当前 Business 内置了这些玩法：

- 信仰注册、信仰信息、弃誓、职业选择。
- 每日祈祷、虚空祈求、捡垃圾。
- 物品开启、背包物品出售。
- 称号、称号加成、图鉴收藏。
- 椰汁俱乐部、会员贡献、救济和分成。
- 恶魔轮盘，包括普通、赌徒和疯狂模式。
- 神性容器、觐献、从神和真神晋升。
- 创造者管理命令。

## Core 为什么重要

Core 是 CoCoFaith 的数据底座。它会创建 `faith_core_` 前缀的数据表，用来保存玩家资料和资产。

玩家数据绑定到 CoCoFaith UID，而不是只绑定某一个平台账号。这样以后接入其他平台，或进行 QQ 官方机器人与 OneBot QQ 绑定时，可以把多个身份指向同一个 UID。
