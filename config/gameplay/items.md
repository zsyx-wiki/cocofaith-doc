# 物品

虚空祈求、开启箱子及其他玩法获得的物品保存在角色库存中。出售和开启操作仅支持群聊。

## 出售

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `信仰 卖出 [物品名] [数量]` | 出售指定数量，不填数量默认为 1 |
| `信仰 卖出 [物品名] 全部` | 出售该物品全部数量，`全部` 也可写成 `all` |
| `信仰 卖出等级 [等级]` | 批量出售对应等级的物品，每种保留 1 件 |
| `信仰 强制卖出等级 [等级]` | 批量出售对应等级的全部可出售物品，不保留 |

</div>

`卖出` 可写成 `出售`，`卖出等级` 可写成 `出售等级`；`强制卖出等级` 也支持 `强制出售等级`、`全卖等级`。

<CommandTerminal scenario="sale" />

<div class="cf-doc-table">

| 检查项 | 规则 |
| --- | --- |
| 物品 | 必须允许出售，且售价大于 0 |
| 指定数量 | 1～1000000 的整数，不能超过持有量 |
| 按等级出售 | 跳过不可出售或没有有效售价的物品 |
| 所得金币 | 按物品售价 × 数量发放，不乘普通收益加成 |

</div>

例如持有同一种 D 级物品 5 件，`卖出等级 D` 出售 4 件、保留 1 件；`强制卖出等级 D` 则出售全部 5 件。

已点亮的图鉴记录不会因出售而消失。但神性容器晋升真神需要消耗实际持有的 SP 道具，仅有图鉴记录不能充当祭品。

## 开启

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `信仰 打开 [物品名] [数量]` | 开启指定数量，不填数量默认为 1 |
| `信仰 打开 [物品名] 全部` | 开启该物品的全部持有量 |

</div>

`打开` 的别名为 `开启`，`全部` 也可写成 `all`。

<div class="cf-doc-table">

| 数量情况 | 处理 |
| --- | --- |
| 不填数量 | 开启 1 件 |
| 指定数量 | 必须为正整数，且持有量足够 |
| 单次开启 | 最多 100 件 |
| 使用“全部”，但库存超过 100 | 拒绝本次操作，需要分批指定数量 |

</div>

只有具有开启规则的物品可以打开；普通道具不能因为使用这条命令就被消耗。

<CommandTerminal scenario="open" />

可开启物品会消耗自身，并发放对应金币、物品或固定奖励。普通箱子的默认规则如下，金币在区间内随机获得，每次另掉落 1 件物品：

<div class="cf-doc-table">

| 箱子等级 | 金币 | 掉落物品等级与权重 |
| --- | --- | --- |
| D | 20～40 | D 60%、C 35%、B 5% |
| C | 35～65 | D 30%、C 40%、B 25%、A 5% |
| B | 70～150 | C 50%、B 35%、A 15% |
| A | 130～220 | B 50%、A 30%、S 15%、SS 5% |
| S | 200～400 | A 50%、S 30%、SS 15%、SSS 5% |

</div>

### 特殊礼盒

特殊礼盒使用自己的规则，不套用普通箱子表。

<div class="cf-doc-table">

| 物品 | 必得资源 | 独立额外掉落 |
| --- | --- | --- |
| 2025圣诞礼盒 | 200 金币、20 登神分 | 藏品柜 15% 与 5% 两次独立判定；保险柜 10%；被遗忘的圣诞袜 1% |
| 神秘请柬 | 100 金币、10 登神分 | 藏品柜 15%；保险柜 20%；流光剧院的过期邀请 2% |

</div>

每项额外掉落独立判定，可以同时得到多件。圣诞礼盒的藏品柜可以两次都命中，得到 2 件。

开启得到的货币均为固定发放，不再叠加普通收益加成。
