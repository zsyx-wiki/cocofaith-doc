# 创造者管理

这些命令需要 `faith.creator` 权限，普通用户执行时可能没有回复。

QQ 接入下由适配器中配置的创造者平台身份识别；群管理员或 Koishi 用户权限等级不会自动等同于创造者。

当前 OneBot 适配器没有单独的创造者账号列表配置。

通过 QQ 适配器识别为创造者的 UID，绑定 OneBot 后可在该身份下使用；仅部署 OneBot 时，需要另外提供相应权限授权。

发送 `信仰管理` 可查看当前已启用玩法注册的管理命令。

## 数值调整

```text
信仰管理 数值 [数值名] [qq|uid] [目标] [变化值]
信仰管理 数值 全体 [数值名] [变化值]
```

例如：

<CommandTerminal scenario="admin-values" />

<div class="cf-doc-table">

| 参数 | 含义 |
| --- | --- |
| `uid` 目标 | 直接使用角色 UID |
| `qq` 目标 | 使用已经关联 UID 的 OneBot QQ 号 |
| 正数变化值 | 增加该数值 |
| 负数变化值 | 扣除该数值 |
| `0` | 不接受 |

</div>

变化值不是目标余额。例如原有 100 金币，变化值填 300 后得到 400，而不是变为 300。

<div class="cf-doc-table">

| 数值名 | 作用 |
| --- | --- |
| 金币 | 角色金币 |
| 登神分数 | 角色登神分 |
| 觐见分数、觐神分数 | 同一角色觐见分字段 |
| 弃誓次数 | 累计弃誓次数，会影响后续弃誓费用 |
| 永久祈祷 | 永久增加的每日祈祷次数 |
| 临时祈祷 | 当天有效的额外祈祷次数 |
| 祈求上限 | 永久增加的每日虚空祈求次数 |
| 额外祈求 | 当天有效的额外虚空祈求次数 |
| 奖励祈求 | 用完每日次数后消耗的额外祈求次数 |
| 俱乐部缴费次数 | 会员累计缴费次数 |
| 俱乐部金币贡献 | 会员累计金币贡献 |
| 俱乐部登神贡献 | 会员累计登神分贡献 |
| 神性 | 已有容器中的神性 |
| 觐献次数 | 已有容器的可用觐献次数 |

</div>

玩法字段只在对应模块启用时提供。货币和次数通常要求整数；觐见分、神性等字段按各自规则校验。

全体调整针对活跃用户执行，各玩法自身的前置条件仍需满足，回复会统计成功、跳过和失败数量。

## 称号

```text
信仰管理 称号 [uid] 给予 [称号名]
信仰管理 称号 [uid] 收回 [称号名]
```

只能操作已定义的称号；给予会员同名称号不会自动创建有效会员身份。

## 图鉴维护

```text
信仰管理 图鉴 刷新 [uid]
信仰管理 图鉴 全量刷新
```

根据目前持有物品补录图鉴，并检查对应收集称号。刷新不能推断从未记录且已经出售的历史物品。

## 俱乐部

```text
信仰管理 俱乐部 分成
信仰管理 俱乐部 总贡献 [+/-数值]
信仰管理 俱乐部 总贡献 [金币或登神分] [+/-数值]
```

<div class="cf-doc-table">

| 操作 | 修改内容 |
| --- | --- |
| `俱乐部 总贡献 [变化值]` | 公共金币池与登神分池同时变化 |
| `俱乐部 总贡献 [币种] [变化值]` | 只修改指定币种的公共池 |
| `数值 俱乐部金币贡献 ...` | 只改个人累计贡献，不改公共池 |
| `数值 俱乐部登神贡献 ...` | 只改个人累计贡献，不改公共池 |

</div>

分成规则见 [椰汁俱乐部](./club#分成)。

<CommandTerminal scenario="admin-club" />

## 神性容器

```text
信仰管理 容器 查看 [uid]
信仰管理 容器 发放 [uid]
信仰管理 容器 撤销从神 [uid]
```

<div class="cf-doc-table">

| 操作 | 结果 |
| --- | --- |
| 向未持有者发放 | 获得神性容器 |
| 向已持有者发放 | 获得神性碎片 |
| 撤销从神 | 收回从神身份、对应称号和晋升资源奖励，神性清零 |
| 撤销真神 | 当前没有通过这条命令撤销真神的功能 |

</div>
