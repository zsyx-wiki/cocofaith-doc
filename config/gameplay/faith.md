# 信仰与职业

选择信仰后，角色可以祈祷、选择对应职业，并参与其他玩法。信仰属于六种命途，恶魔轮盘中的命途能力也与此有关。

## 命令

以下命令支持群聊和私聊。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `信仰`、`信仰 信息` | 查看 UID、信仰、职业和角色数值；`信息` 也可写成 `info` |
| `信仰 注册 [信仰名]` | 首次创建角色；`注册` 也可写成 `register` |
| `信仰 弃誓 [信仰名]` | 支付费用，变更当前主信仰 |
| `信仰 职业` | 查看当前职业或可选职业 |
| `信仰 职业 [职业名]` | 尚无职业时选择一个职业 |
| `信仰 职业查看 [信仰名]` | 查看指定信仰的职业 |
| `信仰 变更职业 [职业名]` | 付费更换职业，别名 `信仰 更换职业 [职业名]` |

</div>

## 注册与信仰

<CommandTerminal scenario="faith-register" />

<div class="cf-doc-table">

| 项目 | 规则 |
| --- | --- |
| 初始金币 | 默认 300 |
| 重复注册 | 同一平台身份不能重复创建角色 |
| OneBot 注册 | 需要管理员开放直接注册 |
| 两个平台共用角色 | 先在 QQ 官方机器人注册，再绑定 OneBot；分别注册不会合并 |

</div>

注册时填写下表中的具体信仰名称，不要只填命途名称。

<div class="cf-doc-table">

| 命途 | 固定信仰 |
| --- | --- |
| 生命 | 诞育、繁荣、死亡 |
| 沉沦 | 污堕、腐朽、湮灭 |
| 文明 | 秩序、真理、战争 |
| 混沌 | 混乱、痴愚、沉默 |
| 存在 | 记忆、时间 |
| 虚无 | 欺诈、命运 |

</div>

通过神性容器建立的真神信仰也可供玩家选择，名称以机器人当前可选列表为准。

## 弃誓费用

设此前已经弃誓 `n` 次，本次费用为：

<div class="cf-doc-table">

| 资源 | 默认费用 |
| --- | --- |
| 登神分 | `min(10000, 1200 + 1000 × n)` |
| 觐见分 | `n` |

</div>

<div class="cf-doc-table">

| 本次是第几次弃誓 | 登神分 | 觐见分 |
| --- | --- | --- |
| 第 1 次 | 1200 | 0 |
| 第 2 次 | 2200 | 1 |
| 第 3 次 | 3200 | 2 |
| 第 10 次 | 10000 | 9 |

</div>

登神分费用封顶为 10000，觐见分费用仍随此前次数增加。

必须选择有效且不同于当前主信仰的新信仰。资源不足时不会扣费或变更信仰。

## 职业选择

<div class="cf-doc-table">

| 操作 | 前置条件 | 默认费用 |
| --- | --- | --- |
| `信仰 职业 [职业名]` | 尚未拥有职业 | 免费 |
| `信仰 变更职业 [职业名]` | 已拥有职业，目标不同于当前职业 | 1000 金币 + 50 登神分 |

</div>

选择时有两个要求：

- 填写**具体职业名**，例如“回忆旅者”，不能只填写“法师”。
- 目标职业属于当前主信仰，可先用 `信仰 职业查看 [信仰名]` 查询。
