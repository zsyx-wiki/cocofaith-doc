# 恶魔轮盘

群聊多人轮流射击的生存游戏，分为普通、赌徒和疯狂模式。玩家需要先注册角色。

## 命令

以下命令都以 `恶魔轮盘` 开头。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `恶魔轮盘` | 查看帮助 |
| `恶魔轮盘 发起` | 创建普通模式，别名 `恶魔轮盘 创建` |
| `恶魔轮盘 发起赌徒` | 创建赌徒模式 |
| `恶魔轮盘 发起疯狂` | 创建疯狂模式 |
| `恶魔轮盘 加入` | 加入当前群的等待房间 |
| `恶魔轮盘 退出` | 在等待阶段退出 |
| `恶魔轮盘 开始` | 房主开始游戏 |
| `恶魔轮盘 结束` | 房主解散等待中的房间 |
| `恶魔轮盘 强制结束` | 创造者中止对局 |
| `恶魔轮盘 对局` | 查看当前房间与对局状态 |
| `恶魔轮盘 开枪` | 在自己的回合射击 |
| `恶魔轮盘 恐惧` | 使用沉沦命途能力 |
| `恶魔轮盘 无畏` | 使用沉沦命途能力 |
| `恶魔轮盘 退缩` | 使用沉沦场地能力 |
| `恶魔轮盘 能力 [能力名]` | 通过统一入口使用当前可用能力 |
| `恶魔轮盘 状态` | 查看个人等级、经验、荣誉和各模式战绩 |

</div>

1. 房主选择一种模式发起房间，自己自动加入。
2. 其他玩家发送 `恶魔轮盘 加入`。
3. 人数达到要求后，房主发送 `恶魔轮盘 开始`。

同一机器人在同一群中只能有一个活跃房间。等待房间 **15 分钟**后自动解散。

## 人数与费用

<div class="cf-doc-table">

| 模式 | 默认人数 | 基础门票 | 基础淘汰罚款 |
| --- | --- | --- | --- |
| 普通 | 4～12 人 | 无 | 本局首次非强制淘汰：10 金币、2 登神分；其余淘汰不罚款 |
| 赌徒 | 5～15 人 | 无 | 每名淘汰者 20 金币、10 登神分 |
| 疯狂 | 8～16 人 | 100 金币 | 每名淘汰者 150 金币、75 登神分 |

</div>

### 扣费与返还

<div class="cf-doc-table">

| 情况 | 处理 |
| --- | --- |
| 疯狂模式开局 | 按玩家等级折算门票，再一次性扣费 |
| 任意玩家门票不足 | 整次开局失败，不会只向部分玩家收费 |
| 玩家被淘汰 | 扣除本次罚款，金币或登神分可以变为负数 |
| 等级提供罚款减免 | 按减免后的实际罚款计入奖池 |
| 创造者强制结束 | 退还本局已扣门票与罚款，不发正常奖励或经验 |
| 对局正常结束 | 按结算规则发奖，不退还门票与罚款 |

</div>

普通模式的超时处决等强制淘汰不收罚款，也不占用首次非强制淘汰的罚款名额。

“赢家通吃”中，庄家的基础罚款还要乘以 **开局人数 − 1**，再计算等级减免。

## 回合与命途

### 行动与装填

<div class="cf-doc-table">

| 名称 | 含义 |
| --- | --- |
| 回合 | 当前玩家进行一次行动 |
| 一轮 | 两次重新装填之间的过程；命途的“每轮”“两轮冷却”按装填计算 |
| 行动时限 | 默认 45 秒 |
| 首次超时 | 自动开枪 |
| 本局累计第二次超时 | 直接淘汰，不要求连续超时 |

</div>

座位在开局时随机排列，轮到自己才能行动。空仓通常存活，实弹通常造成淘汰，命途和场地会改变这一结果。

重新装填时，设当前存活人数为 `n`：

<div class="cf-doc-table">

| 弹仓内容 | 数量 |
| --- | --- |
| 实弹 | `floor(n / 2)`，最少 1 颗、最多 5 颗 |
| 空仓 | `n − 1`，最少 1 格 |

</div>

弹仓会打乱顺序。例如 4 人存活时，公共弹仓为 **2 实弹、3 空仓**。

规则中“补入实弹”会优先把一个空仓改为实弹；没有空仓时才增加一格。“加入空仓”则直接增加空仓并打乱弹仓。

### 六种命途

普通、赌徒模式使用主信仰对应的命途。疯狂模式使用本局重新分配的命途。

<div class="cf-doc-table">

| 命途 | 生效条件 | 效果与概率 |
| --- | --- | --- |
| 生命 | 首次需要抵挡实弹 | 80% 概率保命；成功后补入一颗实弹 |
| 生命 | 成功保命后经过两次装填 | 恢复一次 55% 概率保命；再次成功后重新冷却 |
| 虚无 | 实弹命中 | 60% 概率保命；成功后不稳定性 +3 |
| 存在 | 每次装填 | 获得多 2 格空仓的独立弹仓；25% 概率把实弹削减至最多 2 颗 |
| 文明 | 自己空仓存活且射击未取消 | 60% 概率封锁下一人的命途效果；对方行动结束后，自己获得一次 50% 保命机会 |

</div>

**虚无的空仓风险：**每次空仓先令不稳定性 +3，再按 `5% + 不稳定性%` 判定暴毙。

例如初始不稳定性为 0，第一次空仓风险为 **8%**；若期间没有其他变化，第二次为 **11%**。实弹保命也会增加不稳定性。

**混沌的单次判定：**

<div class="cf-doc-table">

| 结果 | 概率 |
| --- | --- |
| 本次判定不改变射击 | 60% |
| 改为另一名存活目标 | 32% |
| 取消这一枪，射向虚空 | 8% |

</div>

这是一次混沌能力判定的概率；场地选择目标等效果仍会影响最终射击。

### 沉沦的主动能力

<div class="cf-doc-table">

| 能力 | 本次行动 | 使用限制 | 存活后的效果 |
| --- | --- | --- | --- |
| 恐惧 | 加入 1 格空仓后开枪 | 使用后经过两次装填才能再次使用 | 无额外守护 |
| 无畏 | 补入 1 颗实弹后开枪 | 每轮 1 次 | 获得一次 60% 保命机会，并再补入 1 颗实弹 |

</div>

无畏守护在重新装填时清除。能力被封锁时不能使用这些主动能力。

## 场地与疯狂模式

### 赌徒场地

赌徒模式从下列 6 种场地中等概率选择，每种约 **16.67%**。

<div class="cf-doc-table">

| 场地 | 规则 |
| --- | --- |
| 生命 | 每名玩家拥有一次 80% 概率的场地保命 |
| 沉沦 | 每轮可使用一次“退缩”：加入一实一空后开枪 |
| 文明 | 开枪前 50% 概率封锁行动者的命途效果 |
| 混沌 | 每次开枪从存活玩家中随机选择目标，可能选中自己 |
| 存在 | 行动后加入 2 格空仓、补入 1 颗实弹；存活的存在命途玩家独立弹仓也会增加两空一实 |
| 虚无 | 首次装填之后，每次重新装填有 66% 概率随机淘汰一人 |

</div>

### 疯狂模式如何选规则

<div class="cf-doc-table">

| 开局组合 | 概率 |
| --- | --- |
| 随机赌徒场地 + 赢家通吃 | 25% |
| 随机赌徒场地 + 低语 | 25% |
| 疯狂场地 | 25% |
| 癫狂场地 | 25% |

</div>

命途另行分配：**10%** 概率只选 1 种命途，**90%** 概率选 3 种，再按座位循环分配。

### 疯狂场地

<div class="cf-doc-table">

| 项目 | 规则 |
| --- | --- |
| 初始场地护盾 | 每人 1 层 |
| 有人死亡 | 其余存活者各恢复 1 层场地护盾，最多 4 层 |
| 普通射击 | 实弹造成 2 点伤害 |
| 疯魔射击 | 每次装填随机指定一名疯魔；其回合连续随机射击，直到出现实弹或无法继续，实弹伤害为 3 |
| 保命效果 | 改为按层抵挡伤害，不再一次免除全部伤害；仍需通过各自概率判定 |

</div>

护盾不足以抵挡全部伤害时仍会淘汰。疯魔连续射击期间会封锁玩家命途，不能照搬普通射击的保命预期。

### 癫狂场地

<div class="cf-doc-table">

| 触发时机 | 概率与效果 |
| --- | --- |
| 需要保命时 | 每人有一次 50% 场地保命 |
| 完成一次射击后 | 15% 概率，从行动者以外的存活玩家中随机淘汰一人 |
| 上项淘汰发生后 | 55% 概率补入一颗实弹 |
| 本次射击为实弹 | 另有 10% 概率，从行动者以外的存活玩家中连锁淘汰一人 |

</div>

随机淘汰和连锁淘汰可以在同一次实弹射击后分别触发；没有符合条件的目标时不执行。

### 赢家通吃与低语

**赢家通吃：**开局随机指定庄家，只奖励最终赢家。

- 庄家被实弹威胁时有额外保命判定，概率为 `47% + (当前存活人数 − 1)%`。
- 庄家淘汰罚款按开局人数放大，见 [人数与费用](#人数与费用)。
- 赢家奖励份额见下方结算表。

**低语：**

<div class="cf-doc-table">

| 事件 | 恐惧值变化 |
| --- | --- |
| 空仓 | +1 |
| 实弹 | +2 |
| 有人死亡 | 等概率 -4 或 +2 |
| 重新装填 | -5 |

</div>

恐惧值最低为 0、最高为 20。射击前恐惧达到 10 时，按 **当前恐惧值 × 2%** 概率直接处决行动者。

例如恐惧为 10 时，处决概率为 **20%**；为 20 时，概率为 **40%**。

## 奖励与成长

### 对局结算

门票池只有金币；罚款池分别累计实际扣除的金币和登神分。

<div class="cf-doc-table">

| 模式与名次 | 基础金币奖励 | 基础登神分奖励 |
| --- | --- | --- |
| 普通第一名 | 20 | 5 |
| 赌徒第一名，结算时金币与登神分均不为负 | 金币罚款池 ×70% | 登神分罚款池 ×70% |
| 赌徒第一名，任意一种余额为负 | 固定 30 | 固定 15 |
| 疯狂第一名，非赢家通吃 | 门票池 ×35% + 金币罚款池 ×30% | 登神分罚款池 ×30% |
| 疯狂第二名，非赢家通吃 | 门票池 ×20% + 金币罚款池 ×17% | 登神分罚款池 ×17% |
| 赢家通吃，庄家获胜 | (门票池 + 金币罚款池) ×90% | 登神分罚款池 ×90% |
| 赢家通吃，其他玩家获胜 | (门票池 + 金币罚款池) ×50% | 登神分罚款池 ×50% |

</div>

结算按以下顺序计算：

1. 计算表中的基础奖励，并四舍五入。
2. 计算轮盘等级收益加成，再四舍五入。
3. 计算角色适用的普通收益加成，发放实际金额。

赌徒负余额时的 **30 金币、15 登神分**是固定发放，不计算后两步加成。

疯狂模式第二名为最后淘汰的玩家。所有玩家都死亡、没有赢家时，不发名次奖励；赢家通吃也不发第二名奖励。

### 经验与升级

<div class="cf-doc-table">

| 成绩 | 获得经验 | 限制 |
| --- | --- | --- |
| 普通第一名 | 2 | 已达 5 级后不再获得 |
| 赌徒第一名 | 4 | 9 级时减半为 2 |
| 疯狂第一名 | 8 | 满级后不再累计经验 |
| 疯狂第二名 | 6 | 满级后不再累计经验 |
| 其他名次 | 0 | — |

</div>

<div class="cf-doc-table">

| 升级区间 | 所需经验 |
| --- | --- |
| 1 → 2 | 10 |
| 2 → 3 | 15 |
| 3 → 4 | 15 |
| 4 → 5 | 20 |
| 5 → 6 | 20 |
| 6 → 7 | 25 |
| 7 → 8 | 30 |
| 8 → 9 | 50 |
| 9 → 10 | 70 |

</div>

升级会扣除该级所需经验，剩余经验继续保留；等级最高为 **10**。

### 等级收益

<div class="cf-doc-table">

| 等级 | 门票减免 | 罚款减免 | 结算收益加成 |
| --- | --- | --- | --- |
| 1 | 0 | 0 | 0 |
| 2～9 | `(等级 − 1) × 6%` | `(等级 − 1) × 4%` | `(等级 − 1) × 2%` |
| 10 | 60% | 40% | 20% |

</div>

例如 5 级对应 **24% 门票减免、16% 罚款减免、8% 结算收益加成**。

### 满级奖励与荣誉

首次达到 10 级，固定获得：

<div class="cf-doc-table">

| 奖励 | 数量 |
| --- | --- |
| 金币 | 1000 |
| 登神分 | 350 |
| 觐见分 | 5 |
| 称号 | 恶魔赌徒 |
| 神性容器 | 启用容器玩法时发放；已经持有则改发碎片 |

</div>

达到 10 级后，再取得疯狂模式第一名，可获得 **1 点轮盘荣誉**。

刚升到 10 级的那一局只发首次满级奖励，不同时发这点荣誉。荣誉用途见 [神性容器投入](./container#投入神性)。

### 消息发送失败

发送失败不会暂停计时。QQ 被动回复过期时可能收不到后续提示，但对局仍会推进。

可以发送 `恶魔轮盘 对局` 查询当前情况。
