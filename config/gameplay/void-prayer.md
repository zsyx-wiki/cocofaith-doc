# 虚空祈求

消耗金币，从虚空中获取随机物品。仅支持群聊。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `虚空祈求` | 祈求 1 次 |
| `虚空祈求 [次数]` | 连续祈求指定次数 |
| `虚空祈求 次数` | 查看当天次数与剩余数量，别名 `虚空祈求 状态` |

</div>

<CommandTerminal scenario="void-draw" />

## 费用与次数

<div class="cf-doc-table">

| 项目 | 默认规则 |
| --- | --- |
| 每日基础上限 | 10 次 |
| 当日前 3 次 | 每次 45 金币 |
| 当日第 4 次起 | 每次 80 金币 |
| 单条命令上限 | 100 次，必须为正整数 |
| 重置时间 | 北京时间每天 07:30 |

</div>

例如当天第一次发送 `虚空祈求 5`，费用为 `3 × 45 + 2 × 80 = 295` 金币。

### 批量祈求如何处理

<div class="cf-doc-table">

| 情况 | 结果 |
| --- | --- |
| 剩余次数足够、金币足够 | 按请求次数祈求 |
| 请求 10 次，但只剩 4 次 | 自动改为 4 次，按这 4 次收费 |
| 金币不足以支付实际总费用 | 整次失败，不扣费、不抽取，也不先抽其中几次 |
| 每日次数和奖励次数都用完 | 拒绝祈求 |

</div>

### 额外次数

<div class="cf-doc-table">

| 来源 | 有效期 | 使用方式 |
| --- | --- | --- |
| 称号、神格提供的上限 | 对应加成生效期间 | 增加每日上限 |
| 永久额外次数 | 持续有效 | 每个游戏日增加相同次数 |
| 临时额外次数 | 当前游戏日 | 切日后失效 |
| 消耗型奖励次数 | 保留到用完 | 先使用每日可用次数，再消耗奖励次数 |

</div>

额外次数不会让当天的前 3 次低价名额重新计算。不同群聊以及绑定后的不同平台共用次数。

## 物品概率

先抽稀有度，再从相应物品池中选取物品。默认概率如下：

<div class="cf-doc-table">

| 稀有度 | 概率 |
| --- | ---: |
| SP | 0.05% |
| SSS | 0.43% |
| SS | 1.52% |
| S | 3.74% |
| A | 8.97% |
| B | 16.08% |
| C | 31.88% |
| D | 37.33% |

</div>

### SP UP 物品

默认名单：

- 真理仪轨
- 忆妄之镜
- 骨仆赎罪者子嗣之戒
- 骨仆乐乐尔之戒

先按上表判定是否抽中 SP，再选择具体物品。

<div class="cf-doc-table">

| 当前 UP 名单中的可用条目 | SP 物品选择范围 |
| --- | --- |
| 至少有 1 件可用 | 从这些可用 UP 物品中等概率选择 |
| 没有可用条目 | 从常规 SP 池中选择 |

</div>

**UP 不提高 SP 稀有度的概率**，默认仍为 0.05%。

### 彩蛋判定

<div class="cf-doc-table">

| 阶段 | 条件与结果 |
| --- | --- |
| 常规抽取结果 | 必须为 SS、SSS 或 SP，其他等级不判定彩蛋 |
| 额外判定 | 5% 概率尝试从可获取彩蛋中选择一件 |
| 已持有或本次已获得同种彩蛋 | 不重复发放，也不会改抽另一种作为补偿 |
| 次数消耗 | 彩蛋额外掉落，不再消耗祈求次数 |

</div>

这里的 **5% 是抽中高稀有度后的条件概率**，不是每次祈求都有 5% 概率获得彩蛋。

物品会进入角色库存并记录收藏。后续操作见 [物品](./items) 和 [图鉴](./collection)。

管理员可调整 [虚空祈求配置](/config/business#虚空祈求-voidprayer)。
