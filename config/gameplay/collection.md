# 图鉴

图鉴记录角色曾经获得的物品。物品被出售或消耗后，已经点亮的记录仍然保留。支持群聊和私聊。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `图鉴` | 查看图鉴命令帮助 |
| `图鉴 查看` | 查看收藏进度 |
| `图鉴 详情 [页码]` | 查看常规高稀有度物品和彩蛋的点亮情况 |
| `图鉴 限定详情 [页码]` | 查看限定收藏条目 |

</div>

页码从 1 开始，不填默认为第 1 页，每页 12 项。

## 统计范围

<div class="cf-doc-table">

| 查询 | 展示内容 |
| --- | --- |
| `图鉴 查看` | 按当前目录统计各分类、各收藏池的进度 |
| `图鉴 详情` | 常规池中的 EX、SP、UR、SSS 物品，以及彩蛋 |
| `图鉴 限定详情` | 限定收藏池条目 |

</div>

图鉴包括符合目录规则的天赋、道具、彩蛋等；可开启箱子和礼盒不作为普通收藏条目。

### 容易混淆的地方

- **详情页不等于完整目录。**低稀有度物品可能计入总进度，但不出现在稀有详情中。
- **点亮不等于持有。**出售或消耗后仍保留点亮，不能据此判断实际库存。
- **常规与限定分开。**限定条目不参与常规收集称号的完成判定。

## 收集称号

<div class="cf-doc-table">

| 称号 | 获得条件 | 加成 |
| --- | --- | --- |
| 彩蛋收藏家 | 集齐常规彩蛋 | 每日虚空祈求上限 +5 |
| 大收藏家 | 集齐常规 SSS 物品 | 每日虚空祈求上限 +5 |
| 虚空收藏家 | 集齐常规 SP 物品 | 每日虚空祈求上限 +10，费用降低 20% |

</div>

获得新物品时会更新记录并检查对应称号。需要修复历史收藏记录时，可请创造者执行 [图鉴刷新](./admin#图鉴维护)。
