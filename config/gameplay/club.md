# 椰汁俱乐部

俱乐部提供会员收益加成、公益贡献池与救济。命令仅支持群聊，入口 `俱乐部` 也可写成 `椰汁俱乐部`。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `俱乐部`、`俱乐部 信息` | 查看会员信息和贡献池，`信息` 的别名为 `详情` |
| `俱乐部 加入` | 加入或恢复缴费 |
| `俱乐部 退出` | 停止后续缴费 |
| `俱乐部 贡献 [金币或登神分] [数值]` | 主动贡献正整数资源，`贡献` 的别名为 `捐赠` |
| `俱乐部 救济` | 满足条件时领取当天救济 |

</div>

## 会费与等级

### 会费

<div class="cf-doc-table">

| 情况 | 金币 | 登神分 |
| --- | --- | --- |
| 第一次加入 | 2000 | 200 |
| 之后每个游戏日续费 | 200 | 20 |
| 当天已缴费，退出后再次加入 | 不重复收费 | 不重复收费 |
| 其他游戏日重新加入 | 按每日费用收取 | 按每日费用收取 |

</div>

每日续费由游戏日任务执行，默认切日时间为北京时间 **07:30**。

### 个人贡献与公共池

<div class="cf-doc-table">

| 行为 | 个人累计贡献 | 公共贡献池 |
| --- | --- | --- |
| 初次会费 | 按实际支付额增加 | 实际支付额 ×1.1，向下取整 |
| 每日会费 | 按实际支付额增加 | 实际支付额 ×1.1，向下取整 |
| 主动贡献 | 按实际支付额增加 | 实际支付额 ×1.1，向下取整 |

</div>

例如贡献 500 金币，个人贡献增加 **500**，公共金币池增加 **550**。

### 会员等级

下表中的缴费次数与贡献条件需要**同时满足**。缴费次数按成功缴费累计，不等于自然天数。

<div class="cf-doc-table">

| 会员等级 | 累计条件，需同时满足 | 金币收益加成 | 登神分收益加成 |
| --- | --- | ---: | ---: |
| 公益椰汁 | 加入俱乐部 | 20% | 10% |
| 银牌椰汁 | 缴费 30 次、金币贡献 20000、登神贡献 1000 | 30% | 15% |
| 金牌椰汁 | 缴费 60 次、金币贡献 30000、登神贡献 2000 | 40% | 20% |
| 荣誉椰汁 | 缴费 90 次 | 50% | 25% |
| 殿堂椰汁 | 缴费 300 次、金币贡献 100000、登神贡献 5000 | 50% | 25% |

</div>

首次加入获得“好椰汁”称号；完成其他等级条件后获得对应称号。

### 退出与续费失败

<div class="cf-doc-table">

| 身份 | 主动退出或余额不足后 |
| --- | --- |
| 公益、银牌、金牌、荣誉 | 停止缴费，会员收益加成失效；保留历史贡献与已有称号 |
| 殿堂 | 停止缴费，仍保留有效身份、收益加成和分成资格 |

</div>

普通会员以后可重新加入，恢复缴费与有效身份。仅佩戴同名称号不会替代会员资格。

## 主动贡献

需要当前拥有有效会员身份，贡献数量必须为正整数，且对应资源余额足够。

贡献只增加贡献额，**不会增加缴费次数**。

<CommandTerminal scenario="club-donate" />

## 救济

需要同时满足以下条件，不要求已经加入俱乐部：

<div class="cf-doc-table">

| 条件 | 默认要求 |
| --- | --- |
| 角色 | 已注册 |
| 当前金币 | 严格低于 2000 |
| 当前登神分 | 严格低于 600 |
| 当天领取记录 | 本游戏日尚未领取 |
| 公共贡献池 | 至少有 300 金币和 40 登神分 |

</div>

领取后固定获得 **300 金币和 40 登神分**，由公共贡献池支出，不再计算收益加成。

金币恰好为 2000，或登神分恰好为 600，都不满足条件。任一条件不满足时，整次领取失败。

## 分成

分成由创造者执行 `信仰管理 俱乐部 分成`，**不会每天自动发放**。

### 谁可以参加

<div class="cf-doc-table">

| 会员 | 分成资格 | 等级系数 |
| --- | --- | --- |
| 公益、银牌 | 无 | 0 |
| 金牌、荣誉 | 会员身份有效时有资格 | 1 |
| 殿堂 | 有资格，停止缴费后仍保留 | 1.3 |

</div>

个人计算权重需要大于 0。

### 贡献池如何分配

每种资源分别按以下步骤处理：

1. 从公共池取出 **50%**，向下取整。
2. 将取出部分的 **80%** 用于分成，向下取整。
3. 取出部分剩余的 **20%**消耗；没有取出的另一半保留。

例如公共池有 100000 金币：

<div class="cf-doc-table">

| 去向 | 金币 |
| --- | --- |
| 本次分给会员 | 40000 |
| 本次消耗 | 10000 |
| 留在公共池 | 50000 |

</div>

### 每人分多少

```text
个人权重 = (累计缴费次数 + floor(金币贡献 / 3000) + floor(登神贡献 / 700)) × 等级系数
个人份额 = 本次可分配资源 × 个人权重 / 全体合资格会员权重之和
```

先给每人份额向下取整；余数按小数部分从大到小补发，每次补 1，直至分完。小数部分相同时优先 UID 较小的玩家。

分成属于固定发放，不再乘会员或其他普通收益加成。

数值设置见 [俱乐部配置](/config/business#椰汁俱乐部-club)。
