# 神性容器与真神

神性容器用于积累神性、兑换觐见分，并晋升从神和真神。命令支持群聊和私聊。

## 命令

`容器` 的别名为 `神性容器`。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `容器`、`容器 查看` | 查看身份、神性、加成和觐献次数；`查看` 的别名为 `状态` |
| `容器 投入 轮盘赌荣誉 [数量]` | 消耗轮盘荣誉增加神性 |
| `容器 投入 神性碎片 [数量]` | 消耗碎片增加神性；`投入` 的别名为 `注入` |
| `容器 觐献 [次数]` | 消耗神性与觐献次数，换取觐见分，默认 1 次 |
| `容器 从神 [神名]` | 凝聚从神神格 |
| `容器 真神 [神名] [命途] [SP 道具名]` | 晋升真神并建立信仰 |
| `真神 设置祷词 [祷词]` | 为自己创建的信仰设置祷词 |
| `真神 设置职业 [职业类型] [职业名]` | 为自己创建的信仰设置职业 |

</div>

## 获得容器

<div class="cf-doc-table">

| 获得方式 | 条件 |
| --- | --- |
| 恶魔轮盘满级奖励 | 首次达到 10 级，且容器玩法已启用 |
| 创造者发放 | 创造者执行 `信仰管理 容器 发放 [uid]` |

</div>

<div class="cf-doc-table">

| 发放时的库存 | 实际获得 |
| --- | --- |
| 没有容器 | EX 级神性容器 ×1 |
| 已经持有容器 | EX 级神性碎片 ×1 |

</div>

容器和碎片均不可出售。每名玩家只能持有一个容器。

### 三个神性上限

<div class="cf-doc-table">

| 数值 | 默认值 | 含义 |
| --- | --- | --- |
| 神性总容量 | 300 | 正常积累最多达到此值 |
| 手动投入上限 | 250 | 到达后不能继续投入荣誉或碎片，只能等每日滴落 |
| 收益加成计入上限 | 150 | 超出部分仍可消耗，但不再提高容器的收益加成 |

</div>

**150 不是每日滴落的停止上限。**神性高于 150 后仍可以每日积累，直到达到 300。

### 每日滴落

每个游戏日结算一次，默认在北京时间 07:30 切日后由定时任务执行。

<div class="cf-doc-table">

| 本次滴落神性 | 概率 |
| --- | --- |
| 0.5 | 45% |
| 1 | 35% |
| 1.5 | 20% |

</div>

达到总容量后不再增加。机器人重启只补当前游戏日任务，不按离线天数逐日补发。

### 容器收益加成

有效神性取 `floor(min(当前神性, 150))`，即先限制到 150，再向下取整。

<div class="cf-doc-table">

| 有效神性 | 金币收益加成 | 登神分收益加成 |
| --- | --- | --- |
| 每 1 点 | +0.2% | +0.15% |
| 50 点 | +10% | +7.5% |
| 100 点 | +20% | +15% |
| 150 点及以上 | +30% | +22.5% |

</div>

例如当前神性为 50.8，按 50 点计算。消耗神性后，这部分加成也会随之下降。

## 投入神性

投入数量必须为正整数。兑换率按**本次投入前**的神性选择，同一批投入不会中途换档。

<div class="cf-doc-table">

| 投入前神性 | 每点轮盘赌荣誉 | 每个神性碎片 |
| --- | --- | --- |
| 0～50，含 50 | 0.75 神性 | 15 神性 |
| 高于 50～100，含 100 | 0.6 神性 | 15 神性 |
| 高于 100～150，含 150 | 0.5 神性 | 10 神性 |
| 高于 150、低于 250 | 0.45 神性 | 10 神性 |
| 达到 250 | 不能继续投入 | 不能继续投入 |

</div>

例如神性为 50 时，一次投入 2 点轮盘荣誉，获得 `2 × 0.75 = 1.5` 神性。

::: warning 接近上限时注意数量
指定数量会全部消耗，实际神性只增加到 250，超出的兑换量不退还。

例如神性为 245 时投入 1 个碎片，消耗整个碎片，但只增加 5 神性。
:::

当前不支持投入竞标荣誉。

## 觐献

<div class="cf-doc-table">

| 项目 | 默认值 |
| --- | --- |
| 初始机会 | 1 次 |
| 每游戏日恢复 | 2 次 |
| 可储存上限 | 16 次 |
| 每次消耗 | 4 神性 + 1 次机会 |
| 每次获得 | 1 觐见分 |

</div>

例如觐献 2 次，需要 **8 神性和 2 次机会**，获得 **2 觐见分**。

批量操作需要足额资源；神性或机会不足时，整次操作失败，不会先执行一部分。

## 晋升从神

### 晋升条件

<div class="cf-doc-table">

| 条件 | 要求 |
| --- | --- |
| 当前身份 | 凡身，尚未成为从神或真神 |
| 角色 | 已有信仰并持有容器 |
| 当前神性 | 至少 150 |
| 神名 | 2～5 个字符，不与已有信仰或称号重名 |

</div>

晋升会**消耗 150 神性**，不是检查历史上是否累计获得过 150。

### 一次性奖励

<div class="cf-doc-table">

| 奖励 | 数量 |
| --- | --- |
| 金币 | 5000 |
| 登神分 | 500 |
| 觐见分 | 5 |
| 称号 | 所选从神神名 |

</div>

这些资源固定发放，不再乘普通收益加成。身份加成见下方 [神格加成](#神格加成)。

## 晋升真神

### 晋升条件

<div class="cf-doc-table">

| 条件 | 要求 |
| --- | --- |
| 当前身份 | 从神 |
| 当前神性 | 至少 250 |
| 神名 | 恰好两个汉字，不与已有信仰或称号重名 |
| 命途 | 生命、沉沦、文明、混沌、存在、虚无之一 |
| 祭品 | 实际持有的、可出售的常规 SP 级道具 ×1 |

</div>

从神晋升已经消耗的神性不抵扣这次费用，需要重新积累到 **当前 250 神性**。

### 晋升费用

设所选命途中此前已有 `n` 个由容器建立的真神信仰：

<div class="cf-doc-table">

| 资源 | 消耗 |
| --- | --- |
| 神性 | 250 |
| SP 祭品 | 指定道具 ×1 |
| 金币 | `100000 + 15000 × n` |
| 登神分 | `5000 + 1500 × n` |

</div>

<div class="cf-doc-table">

| 该命途此前真神数量 | 金币费用 | 登神分费用 |
| --- | --- | --- |
| 0 | 100000 | 5000 |
| 1 | 115000 | 6500 |
| 2 | 130000 | 8000 |

</div>

计数只看**所选命途**中由容器创建的信仰，不看其他命途，也不把固定信仰算进去。

### 晋升结果

1. 消耗神性、货币和指定祭品。
2. 建立与神名相同的新信仰，自己的主信仰切换到它。
3. 获得真神称号与真神身份加成。

其他玩家之后可通过注册或弃誓选择该信仰。图鉴中点亮过 SP 道具不等于持有祭品，必须有实际库存。

### 神格加成

真神会保留从神加成，再增加真神部分；不是用真神数值替换从神数值。

<div class="cf-doc-table">

| 加成 | 从神 | 真神额外增加 | 真神最终神格合计 |
| --- | --- | --- | --- |
| 金币收益 | +25% | +50% | +75% |
| 登神分收益 | +15% | +30% | +45% |
| 每日虚空祈求上限 | +10 次 | +50 次 | +60 次 |
| 每日祈祷上限 | +1 次 | 无 | +1 次 |

</div>

上表不含容器当前神性、会员和称号等其他来源。

例如默认祈求基础上限为 10 次，没有其他次数来源的真神每日可祈求 **70 次**。

## 真神设置

只有新信仰的创建者，并且仍拥有有效真神身份，才能修改它的设置。

### 设置祷词

<div class="cf-doc-table">

| 项目 | 要求 |
| --- | --- |
| 格式 | 四个汉字 + 中文逗号 + 四个汉字 |
| 合法示例 | `椰风轻拂，神光降临` |
| 唯一性 | 不能与其他信仰的祷词冲突 |
| 信徒使用 | 直接发送完整祷词，进行每日祈祷 |

</div>

### 设置职业

<div class="cf-doc-table">

| 项目 | 规则 |
| --- | --- |
| 职业类型 | 可沿用战士、法师、牧师、刺客、猎人、歌者，也可自定义；不能包含空白 |
| 职业名称 | 1～5 个字符，不能占用其他职业的名称 |
| 修改同一类型 | 替换该类型原职业名，并同步已选择该职业的角色 |
| 信徒查询 | `信仰 职业查看 [信仰名]` |
| 信徒选择 | `信仰 职业 [职业名]`；已有职业时按变更职业规则处理 |

</div>

<CommandTerminal scenario="container-custom" />

数值设置见 [神性容器配置](/config/business#神性容器-container)。
