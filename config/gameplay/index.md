# 玩法

本篇介绍 **3.0.0-rc.1** 已提供的玩法。文中的费用、概率、次数均为默认值，实际以所在机器人配置和消息回复为准。

第一次游玩，可以先选择信仰和职业，再进行每日祈祷、虚空祈求和捡垃圾。获得的物品可以出售、开启或用于收藏；后续再尝试多人轮盘、俱乐部和登神。

## 命令怎么读

示例中的方括号表示需要填写的参数，不要把括号一起发送。例如 `虚空祈求 [次数]` 可以写成 `虚空祈求 3`。命令和参数之间使用空格，多个参数也用空格分开。

QQ 适配器默认要求在群里艾特机器人。绑定模式只接收“椰子水”相关命令；普通玩法需要消息适配器处于 `normal` 模式。

除注册、绑定和版本查询等入口外，玩法需要已注册角色。

不同群聊共用角色数据；跨 QQ 官方机器人和 OneBot 使用同一个角色，需要先 [绑定身份](./binding)。

## 资源与次数

<div class="cf-doc-table">

| 资源 | 主要用途 |
| --- | --- |
| 金币 | 虚空祈求、职业变更、会费、登神等 |
| 登神分 | 弃誓、职业变更、会费、登神等 |
| 觐见分 | 弃誓消耗与角色成长 |
| 轮盘荣誉 | 投入神性容器 |

</div>

使用 `信仰 信息` 查看角色数值，轮盘荣誉使用 `恶魔轮盘 状态` 查看。

默认游戏日在北京时间 **07:30** 切换。祈祷、祈求和捡垃圾共用这个时间边界。称号、会员和神格可能提供奖励或次数加成；标注为固定发放的奖励不会再次乘上普通收益加成。

## 收益如何加成

同一种资源适用的普通百分比加成先相加，再作用于基础收益，最后四舍五入。

例如公益会员提供 20% 金币加成，50 点有效神性再提供 10%，合计为 **30%**。基础奖励 100 金币时，实际获得 **130 金币**，不是把 1.2 与 1.1 连乘。

<div class="cf-doc-table">

| 情况 | 是否计算普通收益加成 |
| --- | --- |
| 每日祈祷抽到正数奖励 | 是 |
| 轮盘普通结算奖励 | 是；先算轮盘等级收益，再算角色普通收益加成 |
| 物品出售、开启所得货币 | 否，固定发放 |
| 俱乐部救济、分成 | 否，固定发放 |
| 首次轮盘满级、晋升从神的资源奖励 | 否，固定发放 |
| 每日祈祷的负数结果 | 否，按原值扣除 |

</div>

增加金币收益不会提高 SP 概率，也不会增加捡垃圾的物品件数。次数、费用、概率各按对应玩法的规则计算。

## 小终端怎么用

每个小终端有独立的预设角色，打开时已经执行了第一条展示命令。

- 继续输入命令，会沿用这个终端的示例状态，例如已消耗的金币和当天次数。
- 点击“重置”会重新加载初始示例。
- 不同终端不共用数据，不会连接真实机器人。
- 随机结果使用固定样本，演示掉落不能用于估算真实概率；概率以页面表格为准。
