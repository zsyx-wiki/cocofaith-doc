# 称号

称号可以来自轮盘成长、物品收藏、俱乐部进度、登神或创造者发放。仅支持群聊。

<div class="cf-doc-table">

| 命令 | 作用 |
| --- | --- |
| `称号` | 查看命令帮助 |
| `称号 列表` | 查看已拥有的称号，并标出正在使用的称号 |
| `称号 详情 [称号名]` | 查看已拥有称号的说明、来源与加成 |
| `称号 使用 [称号名]` | 佩戴已拥有的称号，别名 `称号 佩戴 [称号名]` |

</div>

<CommandTerminal scenario="title-detail" />

## 佩戴称号

需要已经拥有该称号。使用新的称号会切换当前展示称号，不会收回原称号。

<CommandTerminal scenario="title-equip" />

## 称号与加成

<div class="cf-doc-table">

| 概念 | 规则 |
| --- | --- |
| 拥有 | 已经解锁该称号，可在列表中看到 |
| 佩戴 | 当前用于展示的一个称号 |
| 称号加成 | 是否要求佩戴，由称号自身规则决定 |
| 内置收集称号 | 拥有后加成即生效，不要求佩戴 |
| 会员身份加成 | 要求有效会员身份，不能用佩戴称号代替 |

</div>

`称号 详情` 只能查询已经拥有的称号。未获得的称号不能通过该命令预览。

<div class="cf-doc-table">

| 来源 | 称号 |
| --- | --- |
| 恶魔轮盘达到 10 级 | 恶魔赌徒 |
| 常规物品收集 | 彩蛋收藏家、大收藏家、虚空收藏家 |
| 加入椰汁俱乐部及完成对应进度 | 好椰汁、银牌椰汁、金牌椰汁、荣誉椰汁、殿堂椰汁 |
| 神性容器登神 | 以所选神名生成的从神、真神称号 |

</div>

已经获得的活动、隐藏或创造者发放称号，也会出现在自己的列表中。

“虚空鉴赏家”“终焉的智者”等称号对应的旧玩法尚未迁移，当前没有对应玩法的自动解锁途径。

俱乐部的资源收益加成由有效会员身份提供，拥有或佩戴同名称号不能替代会员状态。具体见 [椰汁俱乐部](./club)。
