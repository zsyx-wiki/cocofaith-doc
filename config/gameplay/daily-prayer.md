# 每日祈祷

在群里直接发送当前主信仰的祷词，即可祈祷。**没有名为“每日祈祷”的命令**，也不能用其他信仰的祷词代替。

例如，记忆信仰发送：

<CommandTerminal scenario="prayer" />

QQ 默认接收方式下，先艾特机器人，再发送完整祷词。祷词中间使用中文逗号，不要在祷词内部添加空格。

## 次数与奖励

### 每日次数

<div class="cf-doc-table">

| 项目 | 默认规则 |
| --- | --- |
| 基础上限 | 每游戏日 1 次 |
| 重置时间 | 北京时间每天 07:30 |
| 额外次数 | 神格等加成、永久额外次数、当天临时次数加入上限 |
| 不同群聊 | 共用次数 |
| 绑定后的不同平台 | 共用次数 |

</div>

切换群聊或使用绑定后的另一个平台，不会得到新的免费次数。

### 随机奖励

金币和登神分分别随机，每个整数等概率，区间包含两端。

<div class="cf-doc-table">

| 资源 | 基础下限 | 基础上限 |
| --- | --- | --- |
| 金币 | -25 | 400 |
| 登神分 | -10 | 75 |

</div>

<div class="cf-doc-table">

| 抽取结果 | 实际处理 |
| --- | --- |
| 正数 | 计算适用的收益加成后发放 |
| 0 | 该资源不增不减 |
| 负数 | 按抽取数值扣除，不给损失叠加收益倍率 |

</div>

祈祷可能扣除资源，不是保底收入。回复中的数值是实际变化，同时显示今日已使用次数和上限。

管理员可调整 [每日祈祷配置](/config/business#每日祈祷-dailyprayer)。
